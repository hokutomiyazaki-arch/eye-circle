# 目の円トレース（eye-circle）

スマホを顔の正面に持ち、目だけで円上の点を追う試し版。近さの確認と目の合わせは、スマホで動作している fnt-camera-check の部品を使用する。

右回り・左回りをそれぞれ2周し、8方向の「届き・相対的な遅れ・飛び・ずれ」を表示する。回りごとに読み方とカメラの遅れを選び、倍率・中心ずれを補正する。届きはほかの方向との比較であり、医療の検査ではない。

- index.html 単体、ビルドなし、ES module。カメラ利用には HTTPS または localhost が必要。
- `?demo=1`：カメラなしの合成データで開始〜結果を確認。
- `?test=1`：`window.__ec` に記録・合わせ・解析関数を公開。
- 上記の両モードでは Service Worker を登録しない。
- 映像と顔の点は外へ送信しない。初回は MediaPipe を取得する。
- PNG・生記録 CSV 保存、端末内の履歴は最大20回。旧形式の履歴は表示しない。
- スマホは前面カメラ、PC はカメラ選択に対応。
- 詳細・ローカル検証結果：[SPEC.md](SPEC.md)。実機での今回の動作確認は未実施。

構文確認は `<script type="module">` の中身を取り出し、`node --input-type=module --check` へ渡す。合成解析の確認結果は「右上（届き0.72・飛び4回）、左下（届き1.00・飛び9回）」。
