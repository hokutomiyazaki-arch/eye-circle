# 目の円トレース（eye-circle）

画面いっぱいの円の上を動く点を目だけで追い、カメラ（MediaPipe Face Landmarker の黒目の点）で読んだ視線の軌跡を線で残す試し版。
方向8区画ごとに「届き」「遅れ」「飛び（サッカード）」「ずれ」を出し、動きづらい方向を2つ挙げる。

- 公開：https://hokutomiyazaki-arch.github.io/eye-circle/
- カメラなしの見本：`?demo=1`
- 仕様：SPEC.md
- 映像は端末の中だけで処理（送信しない）。記録は localStorage に最大20回
- しきい値（届き 0.8 未満＝届いていない、飛び＝ターゲットの3倍の速さ・幅が半径の12%以上、頭のずれ 0.15）は仮。実測で直す
